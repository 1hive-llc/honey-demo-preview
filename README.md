# Honey juror preview

[Open the browser walkthrough](https://1hive.io/previews/honey/) or download this repository and open `index.html` in a browser. No dependencies, wallet, or tokens are needed.

Review fictional evidence, preview a sample ballot, and follow a separate synthetic appeal. Your choice stays on this page. This is an educational walkthrough, not the Honey CLI, a contract test, a live court, or a way to sign or submit a ballot.
